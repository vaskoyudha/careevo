Catatan untuk implementasi di Careevo

  • Kanan selalu dua baris. Semua varian memakai flex-direction:column dengan dua anak ber-flex — bukan dua kolom berdampingan.
  • Warna bukan baru. --bg-deep, --ocean-deep, --editor-bg (#06202f), --leaf, --warning, dan --brand sudah ada di globals.css.
  • Radius. 14px untuk kontrol produk, 20px untuk bingkai — sesuai DESIGN.md.
  • Kontras. Tombol Jalankan sengaja memakai tinta gelap di atas --warning; ramp --brand-grad tidak dipakai untuk label putih karena tidak lolos AA.
  • Editor. Komponennya sudah ada — kode-view.tsx (CodeMirror). Tata letak ini membungkusnya, bukan menggantikannya.
  • Blok soal. Panel tugas/instruksi butuh jenis blok baru (mis. tipe:"latihan") atau bidang tugas di BlokKode; belum ada di TipeBlok hari ini.
