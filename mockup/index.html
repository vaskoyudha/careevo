Latar belakang

Masalah & solusi

Masalah

Portofolio dan hasil AI mudah dipalsukan. Tanpa attestation, klaim kompetensi tidak bisa diaudit. Cognitive debt naik ketika proses tidak direkam. Biometrik bukan opsi — privasi & inklusivitas.

Solusi

Proses terekam (snapshot, prompt log, timeline), hasil ditandatangani HMAC lintas bahasa, dan audit log append-only tamper-evident. Local-first: aman didemokan offline.

Loop demo

Dari task sampai badge

Acceptance gate per langkah — siap untuk demo 5 menit.

  1. 01

    Check-in & kerjakan task

    IDE-lite: snapshot log + prompt AI + Paste Guard. Gate: auto-save & test hijau.

  2. 02

    Submit + auto-check

    Test suite, Lighthouse, VTS (Vibe Transparency Score). Gate: kriteria minimum lolos.

  3. 03

    Socrates bertanya

    2–3 pertanyaan pemahaman. Gate: terjawab sebelum quorum review.

  4. 04

    Review rubrik 5 kriteria

    Verifikator memberi skor + alasan wajib. Gate: tidak ada silent reject.

  5. 05

    Badge + attestation terbit

    HMAC ditandatangani, entry masuk rantai. Gate: verify publik OK.

Demo Zoom aman: Dexie (IndexedDB) local-first — tidak bergantung jaringan.
